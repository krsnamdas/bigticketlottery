#Bigticket Lottery Lucky Number Chooser 🎰
The Bigticket Lottery Lucky Number Chooser is an AI-powered companion designed to help lottery enthusiasts pick their next set of potential winning numbers. By leveraging the Azure OpenAI Service, this tool moves beyond simple random number generators to provide "lucky" picks based on user-inspired prompts and creative AI logic.

🚀 Features
AI-Powered Predictions: Uses Azure OpenAI (GPT-3.5-turbo) to generate 6-7 unique lucky numbers.

Prompt-Based Interaction: Users can input specific themes, life events, or "gut feelings" to guide the AI's number selection.

Modern UI: A clean, responsive interface built with React and Material UI (MUI) for a premium experience.

Real-time Results: Instant feedback and "wizard-like" interactions to make the lottery experience fun and engaging.

🛠️ Technologies Used
Frontend: React.js

Styling: Material UI (MUI)

AI Engine: Azure OpenAI Service

Environment Management: Dotenv (for secure API key handling)

🏁 Getting Started
To get the Bigticket Lottery Lucky Number Chooser running on your local machine, follow these steps:

Clone the repository:

Bash

git clone https://github.com/krsnamdas/bigticketlottery.git
cd SocialMediaAI
Install the required dependencies:

Bash

npm install
Configure your API keys:

Create a file named .env in the SocialMediaAI folder.

Add your Azure OpenAI key like this:

Plaintext

REACT_APP_AZURE_OPENAI_API_KEY=your_actual_key_here
Note: Ensure your .gitignore file includes .env to keep your keys safe!

Run the application:

Bash

npm start
Access the app: Open your browser and go to http://localhost:3000.
